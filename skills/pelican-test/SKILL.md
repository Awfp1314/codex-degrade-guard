# 鹈鹕骑车测试（手动体检）

这是账号体检，不是写前闸门。写/删前的降智检查由插件钩子自动完成，不要在这里重复。

## 原则

- 必须使用固定原句，不能添油加醋，也不能有其他 skill 干扰会话。
- 空会话、不带历史记忆。
- 判定只看模型自己的表述，不要替它解释。

## 怎么看

首段回复里：

- 出现 `内嵌 SVG` / `内联 SVG`，或出现 `循环`（指骑行动作的循环）→ 疑似被路由到弱模型。
- 出现 `踩踏`、`沿途风景`、`背景移动`（描述背景动态）→ 未见降智。

## 怎么做

1. 优先调用 MCP 工具 `model_degradation_guard.pelican_probe`（可选参数 `model`、`reasoning_effort`）。
2. 如果 MCP 工具不可用，直接运行探针脚本：

```bash
node "${PLUGIN_ROOT}/probes/pelican.cjs"
```

Windows PowerShell：

```powershell
node "$env:PLUGIN_ROOT\probes\pelican.cjs"
```

3. 把探针给出的判定、依据和首段原文如实转述给用户。
4. 探针会在临时目录里生成 HTML。把该文件路径给用户，能出图就出图，让用户直接看到鹈鹕。

## 注意

- 判定不是 100% 准确：`内嵌 SVG` 有误报，`循环` 基本可靠。
- 单次结果不能当作「必须停手」的理由，只作为是否换模型/检查账号的参考。
